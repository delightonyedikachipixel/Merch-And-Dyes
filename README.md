# Merch&Dyes

React + Vite shop. Customers add items to a cart (each with its own quantity and details) and send the order to the owner's WhatsApp.

    npm install
    npm run dev           # local preview at http://localhost:5173
    npm run build         # dist/ folder: upload to Vercel or Netlify
    npm run build:single  # dist-single/index.html: one file that opens by double-click

Owner's WhatsApp number: OWNER_WA at the top of src/App.jsx.
Logo files: src/assets/ (mark.png, wordmark.png, lockup.png).
